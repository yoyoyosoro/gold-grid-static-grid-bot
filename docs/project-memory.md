# StaticGridBot 项目记忆

最后核对日期：2026-09-21

## 项目定位

StaticGridBot 是原生 MQL5、只做多、仅支持 Hedging 账户的黄金网格 EA。它包含上方底仓体系与下方密网体系；没有持仓 SL，风控面板只作 UI 推演，不参与自动交易决策，也不构成收益或安全保证。

## 部署边界

- EA 用于专用账号，不与其他 EA 混挂；正式运行目标是单一 XAUUSD 图表实例。
- 所有持仓、挂单、合并、切分、历史排重和退出路径同时筛选当前 `_Symbol` 与本 EA Magic。
- 项目支持最小 `0.01` 手、以 `0.01` 递增；不承担 `0.001` 手规格。

## v4.02 订单身份

| 用途 | 参数 | 默认 Magic |
| --- | --- | ---: |
| 初始大底仓 | `InpBaseMagic` | 1 |
| 底仓回补碎单 | `InpBaseGridMagic` | 5 |
| 下方密网碎单 | `InpDownMagic` | 2 |
| 底仓体系合并仓 | `InpBaseMergedMagic` | 3 |
| 密网体系合并仓 | `InpDownMergedMagic` | 4 |

新仓职责以 Magic 为准，Comment 只作显示辅助。五个 Magic 必须非零且互不重复。用户确认升级时当前没有初始底仓，因此不需要迁移场内旧底仓身份。

## 合并批次与拆分规则

- 合并来源只允许 Magic 5 的底仓回补碎单或 Magic 2 的密网碎单；初始底仓和已有合并仓不参与再次合并。
- 触发条件按持仓笔数计算。达到 `InpMergeThreshold` 后，只锁定最早成交的恰好一批，多余碎单等待下一批；价格层级不要求连续。
- 碎单身份不再使用当前 `InpMinLot` 判断。改变后续下单手数不会把旧手数碎单排除在外。
- 关闭前持久保存每笔碎单的持仓标识、实际手数和原始 TP。新合并仓手数等于本批实际由 EA 承接的总手数。
- 每个拆分档位保存自己的实际手数；价格达到该笔原始 TP 时，只从所属合并仓平掉该笔原手数。因而 `10 × 0.01 + 10 × 0.02` 会形成 `0.30` 合并仓，并按各自 TP 分别平 `0.01` 或 `0.02`。
- 若逐笔关闭期间某笔先由服务器原始 TP 完整退出，该笔从本批合并体积和拆分阶梯剔除，其余碎单继续合并。历史尚未同步时等待后续 tick；确认是其他未知退出时才取消批次。
- 新合并仓不设统一 TP，并排除通用 TP 更新和全局补切；状态绑定到该合并仓自己的 `POSITION_IDENTIFIER`。
- `InpEmergencyLimit` 仅作兼容和人工警戒，不改变严格批次数量。

## 参数和网格规则

- `InpBaseUpperLimit = 0` 表示尚未配置，EA 在任何删除或交易动作前拒绝启动。
- 参数只校验常见错误：上下限、点数、层数、阈值、最小手数以及五个 Magic。
- 网格和 TP 保留点数输入，实际价格距离为 `输入点数 × _Point`；价格输出按 `_Digits`。
- `InpPureDenseMode` 是明确开关；`true` 时不建立初始大底仓。
- `InpDownLowerLimit` 是网格铺设下限，只过滤目标价低于下限的密网候选挂单。它不限制初始底仓、底仓回补和底仓体系合并，也不撤销先前合法挂单。

## v4.01 风控面板规则

- 风险缓存是成组提交的原子快照；保证金或盈亏计算任一失败，1-7 项和安全灯均显示不可用。
- 参考手数按经纪商品种最小值、最大值和步长选取，不固定假定为 1 手。
- 第 8 项统计当前持仓记录数，第 9 项统计实际手数；不统计挂单。
- v4.02 中底仓类别为 Magic 1、5、3，密网为 Magic 2，密网合并为 Magic 4。

## v4.04 风控面板规则

- 当前 `XAUUSDc` 经纪商在无限/免保证金模式下，`OrderCalcMargin()` 成功返回 `0` 是有效结果；不能再用“保证金必须大于 0”判断计算失败。
- 风控缓存接受 API 成功、有限且非负的保证金值；API 失败、非有限值或负值仍使 1-7 项和安全灯显示不可用。
- 有效零保证金模式下，①②③显示 `$0.00` 与“免保证金”；④⑤⑥⑦继续按有效盈亏基准推演，安全灯不再因零保证金误报追保。
- 第 8 项细分底仓单量、网格单量、网格合并单量和总量；第 9 项细分底仓手数、网格手数、网格合并手数和总手数；两项均不统计挂单。
- 报价点数仍按输入点数乘 `_Point`，输出价格按 `_Digits`，随平台报价精度自适应。

## 运行状态与重启恢复

- 状态按账户、品种和 Magic 隔离，保存起始价、上方/密网切分水位、退出中标志以及每个合并批次的阶梯。
- v4.02 为兼容已存在的密网合并仓状态，主状态命名空间继续沿用 v4.00 的四个原 Magic；新的来源 Magic 会写入具体合并计划键，不会与密网计划混用。
- 启动时核对起始价状态和实际持仓；不存在的旧状态自动清理，可识别的实际原始底仓价用于刷新状态。
- 断网、重启或跳空后按已保存水位逐层追补；30 天历史用于排重，不用现价覆盖旧水位。单 tick 最多提交 20 个补切动作。

## 总目标退出状态机

```text
冻结新交易
  → 删除本 EA 挂单
  → 平掉本 EA 持仓
  → 扫描确认挂单和持仓均为 0
  → 删除状态并卸载 EA
```

任一请求失败时保持“退出中”，后续 tick 继续扫描和重试。
